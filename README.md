# WeDesign — запуск

Терминал не нужен. Всё делается мышью: файлы в GitHub, переменные в Vercel.

## 1. Залейте файлы в репозиторий

Структура должна быть ровно такой:

```
index.html
admin.html
robots.txt
vercel.json
package.json
assets/style.css
assets/app.js
assets/admin.js
api/_lib.js
api/_render.js
api/generate.js
api/order.js
api/claim.js
api/status.js
api/admin.js
api/site.js
api/draft.js
api/health.js
primery/primer-1-barbershop.html
primery/primer-2-kofeynya.html
primery/primer-3-avtoservis.html
```

Папку `primery` заливать **обязательно**: на главной есть блок «Примеры»,
он показывает эти три файла в рамках браузера. Без них там будут пустые окна.

Папки `assets` и `api` создаются так: **Add file → Create new file** и в имени
пишете `api/_lib.js` — GitHub сам сделает папку. Дальше содержимое можно
вставлять копипастой.

## 2. Подключите хранилище

Без него заказы пропадут при первом же засыпании сервера.

Vercel → ваш проект → **Storage** → **Upstash Redis** → Create.
Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
Ничего вручную вписывать не надо.

## 3. Добавьте переменные окружения

Vercel → Settings → **Environment Variables**. Ставьте на все среды
(Production, Preview, Development).

| Имя | Обязательна | Что писать |
|---|---|---|
| `ADMIN_PASSWORD` | да | Пароль от панели. Длинный, не «12345». |
| `ADMIN_SECRET` | да | Любая случайная строка символов на 40+. Ею подписываются входы в панель. |
| `ANTHROPIC_API_KEY` | да* | Ключ модели. |
| `OPENAI_API_KEY` | да* | Альтернатива предыдущему. |
| `KASPI_URL` | нет | По умолчанию `https://pay.kaspi.kz/pay/cwevqlzj` |
| `PRICE_KZT` | нет | Цена, по умолчанию `9990` |
| `LIMIT_PER_IP_DAY` | нет | Бесплатных сборок с устройства в сутки, по умолчанию `4` |
| `LIMIT_GLOBAL_DAY` | нет | Потолок сборок на весь сайт в сутки, по умолчанию `250` |
| `PAY_WINDOW_MIN` | нет | Сколько минут держится бронь суммы, по умолчанию `90` |

\* нужен один из двух.

**Ключ модели вводится только здесь.** В файлах проекта его нет ни в одном
месте — искать бесполезно, и из браузера его не достать.

После добавления переменных нажмите **Redeploy**, иначе они не подхватятся.

## 4. Проверьте, что всё встало

1. Откройте главную, заполните форму, нажмите «Собрать сайт» — должен появиться
   предпросмотр с водяным знаком.
2. Откройте `/admin`, войдите паролем. Сверху должно быть написано
   `хранилище: redis`. Если написано «память» — вернитесь к шагу 2.
3. Нажмите «Собрать сайт» пять раз подряд — на пятый должно прийти
   «Сегодня бесплатных генераций больше нет». Значит лимит работает.

## Как проходит оплата

1. Клиент жмёт «Забрать сайт». Сервер бронирует уникальную сумму:
   9 990 + случайный хвостик, например **10 127 ₸**. Пока бронь жива, эту
   сумму не выдадут никому другому.
2. Клиент платит по вашей ссылке Kaspi ровно эту сумму.
3. Клиент вписывает имя отправителя, номер чека Kaspi и время платежа.
4. Вы открываете `/admin` → «Ждут проверки». В карточке заказа стоит готовый
   список того, что нужно сверить в приложении Kaspi. Совпало — «Платёж
   получен, опубликовать». Не совпало — «Платежа нет».

Панель сама подсвечивает подозрительное: сумма не та, чек уже был в другом
заказе, имя плательщика не похоже на имя в заказе, оплата после истечения брони.

Автоматической выдачи нет ни в каком виде. Сайт становится публичным только
после вашего нажатия.

## Самопроверка

Если что-то не запускается, откройте в браузере:

```
https://ваш-адрес.vercel.app/api/health?key=ВАШ_ADMIN_PASSWORD
```

Страница покажет: какие переменные окружения сервер реально видит (только
имена, без значений), правильно ли выглядит адрес хранилища, есть ли в токене
лишние пробелы, и результат живой попытки записи в Upstash с точным кодом
ошибки. Секреты она не выводит никогда.

Пароль попадёт в логи Vercel как часть адреса — после отладки его лучше
сменить.

## Если что-то не работает

Откройте Vercel → Deployments → верхний деплой → **Logs**, повторите действие
на сайте и посмотрите строку с `[wedesign]`.

| Сообщение на сайте | Что делать |
|---|---|
| Хранилище отклонило запрос (403 или 401) | В `KV_REST_API_TOKEN` лежит read-only токен. Возьмите основной в панели Upstash → REST API. Затем Redeploy |
| Хранилище не найдено (404) | `KV_REST_API_URL` должен начинаться на `https://` и заканчиваться на `upstash.io`, а не `redis://` |
| Сервер не нашёл /api | Папка `api` лежит не в корне репозитория. Либо перезалейте, либо укажите Root Directory в настройках Vercel |
| На сервере не настроен ключ ИИ | Не задан `ANTHROPIC_API_KEY` (или `OPENAI_API_KEY`). После добавления — Redeploy |

Любая переменная подхватывается только после Redeploy. Это причина примерно
половины «ничего не изменилось».

## Что где лежит

- `api/generate.js` — единственный файл, который ходит к модели. Здесь же три
  уровня лимитов: 2 сборки в минуту с устройства, 4 в сутки с устройства и
  общий суточный потолок на весь сайт.
- `api/_render.js` — сборка HTML сайта. **Верстает только сервер**: браузер
  клиента не может прислать свой HTML, потому что HTML у него никто не спрашивает.
- `api/draft.js` — возврат к уже собранному сайту. Модель тут не вызывается:
  человек закрыл вкладку и вернулся — платить второй раз не за что. Черновик
  живёт 30 дней.
- `api/admin.js` — панель. Пароль сверяется побайтово, вход выдаёт подписанный
  токен на 8 часов, 5 неудачных попыток подряд блокируют вход на 15 минут.
- `api/_render.js` → `makeDNA()` — та самая «ДНК дизайна»: 18 палитр, 14 пар
  шрифтов, 8 типов первого экрана, 4 характера движения, 5 скруглений, 3 меню,
  зерно и mesh-градиенты по жребию, плюс случайный порядок 7 блоков. Каждая
  выпавшая комбинация записывается в базу и повторно уже не выпадет.

## Что этот проект пока НЕ делает

Чтобы не обещать лишнего клиентам:

- нет своих доменов вида `mybiz.kz` — сайты живут по адресу `/s/название`;
- нет загрузки файлов: фотографии добавляются ссылкой (https), иначе в галерее
  будут градиентные блоки в цвет сайта;
- нет личного кабинета и регистрации, только код заказа `WD-XXXX`;
- нет автосписаний — каждая оплата разовая и ручная.
